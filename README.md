# 게스트 설문 리포트 도구

Samsung AI Living × Airbnb 게스트 설문 응답을 넣으면 웹슬라이드 리포트 초안을 만들고, 로데이터 엑셀과 16:9 PPT로 내려받는 도구입니다. 주 1회 · 90분 걸리던 정리 작업을 줄이기 위해 만들었습니다.

**바로 열기:** https://kimmia1004.github.io/survey-practice/

- 브라우저(Chrome·Edge 최신 버전 권장)에서 주소를 열면 바로 도구가 나옵니다. 설치·로그인이 필요 없습니다.
- 모든 처리는 내 브라우저 안에서만 일어납니다. 올린 파일은 서버로 전송되지 않습니다.
- 이 저장소에는 도구 파일(`index.html`)만 있고 설문 응답 같은 데이터는 들어 있지 않습니다.

## 사용 순서
1. **파일 올리기:** 내국인·외국인 응답 파일(.xlsx 또는 .csv, 매주 누적본)을 끌어다 놓습니다. 파일 이름은 보지 않고 첫 행 내용으로 종류를 구분합니다.
2. **예약현황 입력:** 한 줄에 한 팀씩 `시작일[~종료일] 이름`으로 적고 "예약현황 적용"을 누릅니다. 예) `6/14~6/15 손*환`. 적용하면 6~9월 달력이 나타나고 응답이 숙박팀과 연결됩니다.
3. **인식 결과 · 주차:** 총 응답 수, 최신 주와 직전 주, 주차별 응답 수, 정량 평균을 확인합니다. 연결하지 못한 응답이 있으면 요약 팝업이 한 번 뜹니다.
4. **Claude 인사이트:** "분석 요청 텍스트 복사" → Claude(조직 계정)에 붙여 넣기 → 받은 답을 칸에 붙여 넣고 "적용". 답에는 `## 파트별 인사이트` / `## 슬라이드별 핵심 메시지` / `## 긍정 VOC` / `## 부정 VOC` / `## 이름 가린 서술형` 다섯 제목이 있어야 합니다.
5. **미리보기 · 내려받기:** "엑셀" 탭은 로데이터 엑셀, "리포트" 탭은 슬라이드 9장(이전·다음 버튼으로 이동)입니다. 각 탭에서 내려받습니다. 파일명은 `Guest Survey Raw Data_기준일.xlsx`, `Deep Dive Report_기준일.pptx`입니다.

## 주요 규칙
- 주차는 월~일, 응답 타임스탬프 기준입니다. 직전 주는 응답이 있는 가장 가까운 이전 주입니다.
- 점수 평균에는 응답 수(n)를 표시하고 "안 해봄"은 평균에서 뺍니다. 응답이 5건 미만인 주에는 "응답 수 적음"이 붙습니다.
- 이름·이메일·전화번호는 읽는 즉시 가립니다(안\*아, D\* Choi). 화면, 저장, 내려받기 어디에도 원문이 남지 않습니다. 단, 분석 요청 텍스트에는 서술형 원문이 들어가므로 조직 Claude 계정에서만 쓰세요.
- 예약현황 연결: 가린 예약자 성함이 같고 응답일이 체크인일 ~ 마지막 숙박일 + 14일 안이면 그 숙박팀으로 봅니다.
- 응답은 도구에서 지울 수 없습니다. 잘못 들어온 응답은 원본 파일에서 빼고 다시 올립니다.
- 인사이트, 숙박팀 연결 결정, 예약현황 입력은 각자의 브라우저에 저장됩니다(다른 사람과 공유되지 않습니다). 새로고침 직후 5번 블록은 비어 보이고, 응답 파일을 올리면 저장된 내용이 다시 나타납니다.
